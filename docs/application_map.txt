TWITTER CLONE APPLICATION MAP
============================

1. MAIN PAGES
-------------
1.1 Home Page (/)
    - Feed of posts from followed users
    - Create new post
    - View all posts
    - Like/Unlike posts
    - Comment on posts
    - Repost posts
    - Bookmark posts

1.2 Profile Page (/profile/:username)
    - User information display
    - Profile picture
    - Cover image
    - Bio
    - Follow/Unfollow button
    - User's posts
    - User's liked posts
    - User's bookmarked posts
    - Edit profile button (for own profile)

1.3 Explore Page (/explore)
    - Discover new users
    - Trending posts
    - Search functionality

1.4 Notifications Page (/notifications)
    - Like notifications
    - Comment notifications
    - Follow notifications
    - Repost notifications

1.5 Bookmarks Page (/bookmarks)
    - List of bookmarked posts
    - Remove bookmarks

1.6 Settings Page (/settings)
    - Account settings
    - Privacy settings
    - Notification settings
    - Theme settings

    - LoadingSpinner.jsx

    - Sidebar.jsx
        * Navigation links

    - RightSidebar.jsx
        * Search bar
        * Trending topics

2.2 Form Components
    - CreatePost.jsx

    - EditProfile.jsx

        * Bio input
        * Save changes button

6. API ENDPOINTS
---------------
6.1 Auth Routes
    - POST /api/auth/register
    - POST /api/auth/login
    - POST /api/auth/logout
    - POST /api/auth/forgot-password

6.2 User Routes
    - GET /api/users/profile/:username
    - PUT /api/users/profile
    - GET /api/users/followers
    - GET /api/users/following
    - POST /api/users/follow/:id
    - POST /api/users/unfollow/:id

6.3 Post Routes
    - POST /api/posts
    - DELETE /api/posts/:id
    - POST /api/posts/like/:id
    - POST /api/posts/comment/:id
    - POST /api/posts/repost/:id
    - GET /api/posts/feed
    - GET /api/posts/user/:username

6.4 Bookmark Routes
    - POST /api/bookmarks/:postId
    - GET /api/bookmarks
    - DELETE /api/bookmarks/:postId

6.5 Notification Routes
    - GET /api/notifications
    - PUT /api/notifications/:id
    - DELETE /api/notifications/:id
