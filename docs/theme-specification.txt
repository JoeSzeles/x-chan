TradeHub Theme Specification
===========================

Color Palette
------------
Primary Colors:
- Primary Blue: #007bff
- Primary Dark: #0056b3
- Primary Light: #80bdff

Secondary Colors:
- Secondary Green: #28a745
- Secondary Red: #dc3545
- Secondary Yellow: #ffc107
- Secondary Gray: #6c757d

Background Colors:
- Main Background: #f8f9fa
- Card Background: #ffffff
- Dark Background: #343a40
- Light Background: #f8f9fa

Text Colors:
- Primary Text: #212529
- Secondary Text: #6c757d
- Light Text: #ffffff
- Link Text: #007bff
- Error Text: #dc3545

Border Colors:
- Default Border: #dee2e6
- Focus Border: #80bdff
- Error Border: #dc3545

Component Styles
---------------
Cards:
- Border Radius: 0.5rem
- Box Shadow: 0 0.125rem 0.25rem rgba(0, 0, 0, 0.075)
- Padding: 1rem
- Margin: 1rem 0

Buttons:
- Primary Button:
  * Background: #007bff
  * Text: #ffffff
  * Hover: #0056b3
  * Border Radius: 0.25rem
  * Padding: 0.375rem 0.75rem

- Secondary Button:
  * Background: #6c757d
  * Text: #ffffff
  * Hover: #5a6268
  * Border Radius: 0.25rem
  * Padding: 0.375rem 0.75rem

- Outline Button:
  * Background: transparent
  * Border: 1px solid #007bff
  * Text: #007bff
  * Hover: #007bff
  * Hover Text: #ffffff

Input Fields:
- Border: 1px solid #ced4da
- Border Radius: 0.25rem
- Padding: 0.375rem 0.75rem
- Focus Border: 1px solid #80bdff
- Focus Box Shadow: 0 0 0 0.2rem rgba(0, 123, 255, 0.25)

Typography
---------
Font Family: 
- Primary: 'Segoe UI', system-ui, -apple-system, sans-serif
- Secondary: Arial, sans-serif

Font Sizes:
- Headings:
  * H1: 2.5rem
  * H2: 2rem
  * H3: 1.75rem
  * H4: 1.5rem
  * H5: 1.25rem
  * H6: 1rem

- Body Text:
  * Regular: 1rem
  * Small: 0.875rem
  * Extra Small: 0.75rem

Line Heights:
- Headings: 1.2
- Body Text: 1.5

Spacing System
-------------
Base Unit: 1rem (16px)

Spacing Scale:
- xs: 0.25rem
- sm: 0.5rem
- md: 1rem
- lg: 1.5rem
- xl: 2rem
- xxl: 3rem

Grid System
----------
- Container Max Width: 1200px
- Grid Columns: 12
- Gutter Width: 1.5rem
- Breakpoints:
  * xs: <576px
  * sm: ≥576px
  * md: ≥768px
  * lg: ≥992px
  * xl: ≥1200px

Component States
--------------
Hover States:
- Buttons: Darken background by 10%
- Links: Underline
- Cards: Slightly elevate with box-shadow

Active States:
- Buttons: Darken background by 20%
- Input Fields: Show focus ring

Disabled States:
- Opacity: 0.65
- Cursor: not-allowed

Error States:
- Border Color: #dc3545
- Text Color: #dc3545
- Background: #fff5f5

Success States:
- Border Color: #28a745
- Text Color: #28a745
- Background: #f0fff4

Animation
--------
Transition Duration: 0.3s
Transition Timing: ease-in-out

Common Animations:
- Fade In/Out
- Slide Up/Down
- Scale
- Rotate

Icons
-----
Icon Size: 1.25rem
Icon Color: Inherit from parent
Icon Spacing: 0.5rem

Special Components
----------------
Service Cards:
- Image Aspect Ratio: 16:9
- Title Font Size: 1.25rem
- Description Font Size: 0.875rem
- Price Font Size: 1.5rem
- Price Color: #28a745

Profile Cards:
- Avatar Size: 3rem
- Name Font Size: 1.25rem
- Bio Font Size: 0.875rem
- Stats Font Size: 1rem

Notification Badges:
- Background: #dc3545
- Text Color: #ffffff
- Size: 1.25rem
- Position: Top-right

Accessibility
------------
Color Contrast:
- Text on Background: Minimum 4.5:1
- Large Text: Minimum 3:1
- UI Components: Minimum 3:1

Focus Indicators:
- Outline: 2px solid #007bff
- Outline Offset: 2px

Responsive Design
---------------
Mobile First Approach:
- Base styles for mobile
- Media queries for larger screens
- Fluid typography
- Flexible grid system

Dark Mode Support
---------------
Dark Mode Colors:
- Background: #212529
- Card Background: #343a40
- Text: #f8f9fa
- Border: #495057
- Primary: #0d6efd
- Secondary: #6c757d

Implementation Notes
------------------
1. Use CSS variables for easy theme switching
2. Implement a consistent spacing system
3. Maintain proper contrast ratios
4. Support both light and dark modes
5. Ensure responsive design across all breakpoints
6. Use semantic HTML for better accessibility
7. Implement proper focus states for keyboard navigation
